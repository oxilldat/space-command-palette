# Changelog

## 0.2.0 — 2026-10-31

- Integrated Oxill Pie Menu into Space Command Palette.
- Added global and per-workspace radial menus with commands and nested folders.
- Added configurable sector icons, colors, activation mode, radius, animation, and sounds.
- Added an interactive radial-menu preview and workspace-aware settings.
- Added a redesigned settings workspace with persistent navigation and per-Workspace icons.
- Added Workspace rename and delete actions with synchronized plugin settings.
- Migrated existing 0.1.x workspace command bindings without data loss.
- Removed mobile support; the combined plugin is desktop-only.

## 0.1.1

- Updated the manifest description for the community plugin directory.
- Improved CSS compatibility with supported Obsidian versions.
- Added automated release artifact attestations.

## 0.1.0

- Added workspace-specific command palettes for Obsidian Workspaces.
- Added command selection and ordering.
- Added Russian, English, and Chinese interface languages.
- Added single-line settings import and export.
- Added missing workspace and unavailable command handling.
- Added author links and release-ready documentation.
